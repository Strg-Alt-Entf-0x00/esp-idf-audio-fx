Audio FX Studio · Hardware & DSP Reference

Hardware Audio Engine Architecture:
• Codec DAC/ADC: ES8311 (I2C 0x18 / I2S0)
• Digital Mic: INMP441 (I2S1 Stereo)
• Clock Source: APLL Audio Clock (48 kHz)
• DMA Ping-Pong: 2× 240 Frames (5.0 ms)

Web Serial Engine: Connect your ESP32-P4 or ESP32-S3 over USB and click the top-right connect icon (115200 Baud). The studio automatically handshakes with TOOL_ID:Strg-Alt-Entf-0x00/esp-idf-audio-fx:console_audio_fx:1 and queries device status.

8 Hardware DSP Algorithms:
• reverb — 8 comb filters with feedback decay + 4 all-pass phase diffusers.
• chorus — Dual-voice modulated stereo delay lines driven by sinusoidal LFOs.
• equalizer — 5-band cascade of direct-form II biquad peaking/shelving filters.
• delay — Up to 1000 ms circular buffer echo with feedback saturation.
• flanger — Resonant sweeping comb filter with positive or negative feedback.
• bitcrusher — Variable word-length quantization and sample-and-hold rate decimation.
• compressor — Peak/RMS linked stereo detector with soft-knee curve and makeup gain.
• limiter — Brickwall limiter with 5 ms lookahead delay and smooth gain release.

Console Command Reference:
tracks — List flash-resident WAV files
play <index> — Play specified WAV track
stop — Stop track playback or live microphone stream
audio start — Begin live microphone-to-speaker audio loop
fx select <name> — Switch active hardware DSP algorithm
fx set <index> <val> — Set specific DSP parameter
fx bypass on|off — Toggle master effect bypass
volume <dB> — Adjust DAC speaker volume (-60.0 to 0.0 dB)
mic_select <codec|inmp441> — Switch active microphone hardware
mic_gain <dB> — Set ES8311 analog pre-amplifier gain (0.0 to 42.0 dB)
diag — Query DMA frame counters and real-time RMS signal levels
